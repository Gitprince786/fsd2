# PostHub

PostHub is a Post Management System built using React and Spring Boot.

## Technologies

### Frontend
- React
- Vite
- React Router
- Axios
- CSS

### Backend
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Bean Validation
- REST API
- SLF4J
- MDC
